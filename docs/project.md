# 팰월드 도우미

팰월드 플레이 보조용 개인 웹사이트. 왼쪽 메뉴는 `지도`, `아이템`, `팰`, `구조물`.

## 기술 스택
- Vite + React + TypeScript, pnpm
- UI: lucide-react 아이콘, 폰트 Noto Sans KR(@fontsource로 번들, 외부 CDN 없음). 팰월드 게임 폰트는 비공개/저작물이라 미사용.
- 정적 데이터: `public/data/items.json`, `public/icons/*.webp`, `public/map/palpagos.webp`

## 기능
- **조합식 + 목표**: 아이템/구조물 상세의 재료는 접힌 계층 트리(현재 항목 제외). `목표 N개 만들기`(항목별 저장), 줄마다 필요(노란색)/보유(입력)/남음과 진행 바, 맨 위에 전체 진행률·남은 재료 종류. 보유량은 아이템 단위로 모든 조합식/창이 공유(`ui.recipe.inventory`), 중간 재료 보유도 하위 재료 요구량에서 차감하며 같은 재료가 여러 줄이면 위에서부터 차례로 사용.
- **지도 표시(위치) 레이어**: 지도 위쪽 중앙에 고정된 가로 아이콘 막대(창 아님, 이동/크기 조절 없음)로 고속 이동/세력 탑/알파 팰/던전을 토글. 호버하면 이름+개수. 마커는 게임 아이콘(알파 팰은 원형 초상화), 줌과 무관하게 화면상 고정 크기. 데이터 `public/data/markers.json` (`scripts/fetch_markers.py`).
- 창 투명도: 포커스는 두 그룹이 따로임 — 목록 창(팰/구조물/아이템)과 상세 창. 각 그룹에서 가장 최근에 쓴 창 하나씩이 동시에 포커스(선명)되고, 나머지 창은 창 전체 opacity 0.3. 왼쪽 레일은 내용 높이만큼만(컴팩트).
- **PC 레이아웃(지도 + 떠 있는 창)**: 지도가 UI 전체로 고정(리렌더/포커스 변경 없음). 아이템/팰/구조물은 지도 위 반투명(40%)+블러(14px) **창**으로 띄움. 레일 버튼 = 목록 창 열기/닫기, 목록에서 항목을 누르면 별도 상세 창(최대 4개, 초과 시 가장 오래된 창 닫힘). 창은 제목줄 드래그로 이동, 모서리 드래그로 크기 조절, 위치/열림 상태는 localStorage에 기억(`ui.windows.v1`). 레일의 눈 버튼 = 모든 창 숨기기(지도만 보기). 앞에 있는 팰 상세 창의 서식 분포가 지도에 찍히고 그 영역으로 이동. URL은 포커스된 상세 창을 따라감(`/pals/Anubis`, 뒤로가기 시 해당 창이 앞으로). 시안: `docs/designs/floating-windows-mock.html`.
- 모바일(<768px): 사이드바 → 하단 탭바, 목록/상세를 한 화면씩(상세 상단 ← 목록 버튼, 라우트 기반이라 브라우저 뒤로가기도 동일), 툴팁은 길게 누르기, 지도는 핀치 확대/드래그.
- 라우팅(react-router): `/items/:id`, `/pals/:id`, `/structs/:id`, `/map/:palId`. 이동마다 히스토리가 쌓여 뒤로가기 동작, 주소 공유 가능. 배포 시 모든 경로를 index.html로 폴백해야 함.
- 폴더 아이콘: 아이템/구조물은 lucide, 팰 속성/작업 적성 폴더는 게임 아이콘 (`src/folderIcons.tsx`).
- 호버 요약 툴팁: 링크된 아이템/구조물/팰에 `data-tip`을 달면 `Tooltip.tsx`가 요약 카드 표시.
- 아이템: 보기 형식 3종(계층 / 목록 가나다순 / 그리드 가나다순, 아이콘 버튼으로 전환, 선택은 localStorage에 기억). 계층은 대분류(typeA) > 소분류(typeB) > 아이템이며 폴더별 개수 표시. 이름 검색(하이라이트). 아이콘은 희귀도별 그라데이션 배경(아래가 밝음).
- 사이드바 접기/펴기(☰, 상태 기억).
- 아이템 상세: 설명, 제작대, 1개당 제작 재료, 하위 재료까지 풀어서 계산한 총 필요 재료(만들 개수 입력). 두 표는 너비가 충분하면 나란히 배치, 재료 행 전체 클릭 시 해당 아이템으로 이동.
- 팰: 299종. 계층 기준을 속성별/작업 적성별로 전환. 상세에 속성, 스탯, 작업 적성(게임 아이콘 + 레벨 숫자 칩, 이름은 툴팁), 파트너 스킬, 서식 구역(레벨), 알, 드롭(아이템 링크), 서식 분포 지도(낮/밤, 상세 안 작은 지도 + 지도 메뉴에서 크게 보기).
- 구조물: 496개, 게임 건설 분류 계층. 상세에 설명, 요구 기술 레벨, 기술 포인트/고대 기술 포인트, 건설 재료, 요구 적성, 여기서 만들 수 있는 아이템. 아이템 상세의 제작대 태그는 구조물로 링크.
- 지도: 팰파고스 제도 맵 이미지(4096px), 휠 확대/축소, 드래그 이동. 마커는 미구현.

## 데이터 출처
- paldb.cc 한국어 페이지를 `scripts/fetch_data.py`, `scripts/fetch_map.py`로 수집. 게임 저작물은 Pocketpair 소유이며 개인 사용 전제.
- 팰/구조물/좌표: `scripts/fetch_pals.py`, `scripts/fetch_structs.py` (좌표는 paldb `/paldex/<코드>.json`을 4096px 지도 픽셀로 변환해 `public/data/spawns/`에 저장).
- 희귀도 변형(예: 돌격 소총 1~5단계)은 페이지당 첫 변형만 사용.

## 알려진 한계
- 팰 서식 구역은 게임 내부 코드(`green_A` 등) 그대로 표시.
- 구조물 중 기술 트리에 항목이 없는 것은 기술 포인트를 `-`로 표시.
- 이름에 `'`가 들어간 2개 아이템(녹사주/모슬론의 깃털·꽃잎 계열)은 URL 인코딩 문제로 수집 실패.
- 총 필요 재료는 "레시피가 없는 아이템"을 기본 재료로 취급.
