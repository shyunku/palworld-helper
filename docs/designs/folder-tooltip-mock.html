폴더 아이콘 종류:

왼쪽 목록 (폴더 아이콘)

여기서 만들 수 있는 아이템 · 마우스를 올려 보세요

바뀌는 것: ① 폴더마다 의미에 맞는 아이콘(위 전환 버튼) — 아이템/구조물은 lucide 아이콘, 팰 속성·작업 적성 폴더는 게임 실제 아이콘. 아이콘이 없는 소분류 폴더는 대분류 아이콘을 작게 따라감. ② 링크로 걸린 항목(재료 행, 칩, 드롭, 제작대 태그, 팰 드롭 등)에 마우스를 올리면 요약 카드가 뜸: 아이콘·이름·등급, 한 줄 설명, 핵심 수치(아이템=제작 재료/제작대, 팰=속성·작업 적성, 구조물=기술 Lv/포인트).
그대로인 것: 클릭 이동, 목록/상세 레이아웃.
사용자가 정할 것: 툴팁을 마우스 따라다니게 할지 / 항목 옆에 고정할지(시안은 옆에 고정), 모바일(터치)에서는 툴팁 대신 길게 누르기로 대체할지.
