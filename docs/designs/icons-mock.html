팰 상세 (아누비스 예시)

아누비스 #139

⛰땅 속성

※ 작업 적성 아이콘은 실제 앱에선 게임 아이콘(수작업/채굴/운반…)이 들어감. 시안에서는 자리 표시용.

바뀌는 것: ① 왼쪽 메뉴의 이모지 → lucide 아이콘(지도·배낭·발바닥·망치), ② 팰 작업 적성 칩: 게임처럼 아이콘 + 굵은 숫자(레벨). 마우스를 올리면 작업 이름이 툴팁으로 뜸.
그대로인 것: 속성 배지(아이콘+이름), 나머지 화면.
폰트: 팰월드 게임 폰트는 공개 정보가 없고 개발사 저작물이라 그대로 쓸 수 없음. 비슷한 느낌의 무료 폰트 후보를 위 버튼으로 비교(본문 / 제목·숫자 따로).
사용자가 정할 것: 작업 적성에 이름을 같이 둘지(B) 아이콘+숫자만(A). 그리고 "팰 속성"을 작업 적성(레벨이 있는 것)으로 해석했음 — 맞는지. (속성=불/물 등은 레벨이 없어서 아이콘만 둠)
