바뀌는 것: 전체 UI가 지도 하나로 고정되고, 아이템/팰/구조물은 지도 위에 떠 있는 창이 됨. 레이아웃이 메뉴별로 바뀌지 않고 지도도 건드리지 않음.
• 레일 버튼 = 창 열기/닫기 토글(켜져 있으면 강조). 여러 창을 동시에 띄울 수 있음. 맨 아래 "모든 창 숨기기" 버튼 하나로 지도만 남김(지도 메뉴/`/map` 주소는 없어짐).
• 창 조작: 제목줄을 드래그해서 이동, 오른쪽 아래 모서리를 드래그해서 크기 조절, 클릭하면 맨 앞으로. 위치/크기/열림 상태는 기억함(새로고침해도 유지).
• 상세는 별도 창: 목록 창에서 항목을 누르면 상세 창이 새로 뜸(같은 항목은 기존 창을 앞으로). 여러 개를 띄워서 비교 가능. 상세 창 ✕로 닫기.
• 팰 상세 창이 맨 앞이면 그 팰의 서식 분포가 지도에 찍히고 해당 영역으로 이동(메뉴를 바꾸거나 다른 창을 열어도 지도는 그대로, 팰 상세 창을 새로 열 때만 이동).
• 패널 투명도 40% / 블러 14px, 지도 밝게는 그대로. 시안 체험: 왼쪽 레일 버튼을 눌러 창을 열고, 목록의 항목을 눌러 상세를 띄우고, 제목줄을 끌어보세요.
그대로인 것: 목록(검색/계층·목록·그리드/폴더 아이콘), 상세 내용, 툴팁, 링크 이동(링크를 누르면 해당 항목 상세 창이 열림). 모바일은 지금처럼 전체 화면 방식 유지(창 방식은 PC만).
사용자가 정할 것: ① 창 최대 개수(시안은 제한 없음, 제안: 상세 창 최대 4개, 넘으면 가장 오래된 것부터 닫음) ② 처음 접속했을 때 기본으로 열려 있을 창(제안: 지도만) ③ 창 끝을 화면 가장자리에 붙이는 스냅 기능이 필요한지.
