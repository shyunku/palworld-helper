② 상세 화면 (/items/:id) — 뒤로가기로 ①

③ 팰 상세 + 분포 지도 (/pals/:id)

④ 지도 (/map)

바뀌는 것 (좁은 화면, 약 768px 미만에서만)
• 왼쪽 사이드바 → 하단 탭바(지도/아이템/팰/구조물). 접기 버튼은 모바일에선 없음.
• 목록과 상세를 한 화면씩 보여줌: 목록에서 항목을 누르면 상세 화면으로 이동(주소도 바뀌어서 뒤로가기 = 목록 복귀). 상세 상단에 ← 뒤로 버튼.
• 목록 상단은 검색창 + 보기 형식 아이콘 3개. 그리드는 3열. 터치하기 좋게 행 높이 44px 이상.
• 상세는 카드가 세로로 쌓임(제작 재료 → 총 필요 재료), 팰 분포 지도는 가로 꽉 차게. 지도 화면은 전체 화면 + 우측 확대/축소 버튼, 두 손가락 확대/드래그 이동.
• 호버 툴팁은 터치에 없으므로 항목을 길게 누르면 같은 요약 카드가 하단에 뜸(③ 화면 하단에 예시). 짧게 누르면 기존처럼 이동.
그대로인 것: 데스크톱(넓은 화면) 레이아웃 전부, 색/폰트/아이콘.
사용자가 정할 것: ① 사이드바를 하단 탭 대신 햄버거 드로어로 할지 ② 툴팁을 길게 누르기로 둘지(아니면 모바일에선 생략) ③ 폰 가로 모드에서는 데스크톱 2단 레이아웃으로 돌려도 되는지.
