예시: ※ 목록 항목을 눌러 보세요 (지도가 이동하고 표시됨)
장소
바뀌는 것: 왼쪽 레일에 장소(핀 아이콘) 메뉴가 추가되고, 누르면 다른 목록 창처럼 떠 있는 장소 목록 창이 열림(이동/크기 조절/기억 동일).
• 검색: 이름으로 검색(일치 글자 강조). 검색 대상은 고속 이동(137) · 던전(170) · 세력 탑(8) · 알파 팰(83) 이름. 위쪽 칩으로 종류별 필터(여러 개 선택, 개수 표시).
• 항목 클릭 → 지도가 그 위치로 부드럽게 이동·확대되고, 깜빡이는 청록 링 + 이름표로 표시됨(해당 레이어 토글이 꺼져 있어도 그 장소는 보임). 다른 항목을 누르면 표시가 옮겨가고, 창을 닫거나 같은 항목을 다시 누르면 해제.
• 알파 팰 항목은 원형 초상화, 나머지는 게임 아이콘. 레벨이 있으면 오른쪽에 "Lv.56" 표시. 지도 위쪽 표시 막대(고속 이동·탑·알파 팰·던전)와 별개로 동작.
그대로인 것: 지도/다른 창/표시 막대. 모바일은 하단 탭에 "장소"가 추가되고 목록 → 선택 시 지도로 이동하는 방식(제안).
사용자가 정할 것: ① 검색 대상에 더 넣을 종류(시안: 4종. 추가 후보: 도시·마을(73), 유적(106), 지역 이름(80), 낚시터 등) ② 항목을 눌렀을 때 창을 그대로 둘지/닫을지(시안: 그대로) ③ 같은 이름이 많은 던전(예: "동굴")은 이름 뒤에 Lv로만 구분할지, 좌표 번호를 붙일지.
