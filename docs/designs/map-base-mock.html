화면: 패널 투명도: 블러: 지도 어둡기: 밝게(확정)
바뀌는 것: 지금의 "사이드바 + 목록 + 상세" 3단 고정 레이아웃 → 지도가 항상 전체 배경이고 그 위에 반투명(블러) 카드 3개가 떠 있음. ① 왼쪽 아이콘 레일(메뉴, 호버하면 이름) ② 그 옆 목록 패널(검색/보기 전환/트리 그대로) ③ 오른쪽 상세 패널(항목 선택 시에만 나타남, ✕로 닫기). 패널 사이·바깥은 지도가 그대로 보이고 드래그/휠로 조작됨.
• 팰을 선택하면 지도가 그 팰의 서식 범위로 자동 이동/확대되고 낮/밤 분포 점이 배경 지도에 바로 찍힘(상세 안의 작은 지도는 불필요해져서 제거, 낮/밤 토글만 상세에).
• 지도 메뉴는 따로 없어지고, 레일의 지도 아이콘은 "패널 모두 숨기기"(지도만 보기) 토글이 됨.
그대로인 것: 항목 데이터와 기능 전부(검색, 계층/목록/그리드, 재료 링크, 툴팁, 라우팅 주소). 색/폰트/아이콘.
사용자가 정할 것: ① 패널 투명도/블러 기본값(위 버튼으로 비교) ② 아이템/구조물에서도 지도를 배경으로 둘지(지금 시안, 지도 밝기는 '밝게'로 확정됨 — 글자 가독성은 패널 투명도/블러로 확보) ③ 상세 패널이 오른쪽에 뜨는 위치(대안: 목록 바로 옆) ④ 모바일은 기존 하단탭 방식 유지(지도 위 바텀시트로 바꿀지는 별도).
