예시: 보유 계산:
바뀌는 것: 조합식 카드가 목표 카드를 겸함(별도 화면 없음).
• 목표 = 기존 "만들 개수"를 "목표 N개"로 바꾼 것. 아이템/구조물마다 저장됨(새로고침해도 유지).
• 각 줄에 보유 입력칸(지금까지 모은 수)이 생기고, 줄 아래에 진행 바(보유/필요), 오른쪽에 남음 수량(부족하면 주황, 다 모으면 초록 "✓"). 필요 수량 = 노란 숫자(목표 반영).
• 카드 맨 위에 전체 진행 요약: 전체 진행률 % + 남은 재료 종류 수. 기본 재료(맨 아래 잎) 기준으로 계산.
• 보유 수는 같은 아이템이면 어디서든 공유(예: 원유를 한 번 입력하면 다른 조합식에서도 같은 값). 줄을 눌러 접고 펼치는 건 그대로.
• 보유 계산 A/B(위 버튼): A는 중간 재료(예: 플라스틸)를 이미 만들어 갖고 있으면 그 하위 재료 요구량이 줄어듦. B는 맨 아래 기본 재료만 입력.
그대로인 것: 조합식 트리 구조/열맞춤/호버 툴팁/링크, 헤더와 다른 카드.
• 같은 재료가 조합식에 여러 번 나오면 입력칸은 맨 위 줄에만 있고, 아래 줄은 위에서 쓰고 남아 배정된 수량을 점선 칸으로 보여줌(보유량을 위에서부터 차례로 사용).
사용자가 정할 것: ① 보유 계산 A/B ② 전체 진행 요약을 둘지 ③ 목표 N개를 아이템마다 따로 저장(시안) vs 하나의 "작업 목록"에 여러 목표를 모아 한 번에 합산 보기(별도 큰 기능, 이번엔 제외 제안).
